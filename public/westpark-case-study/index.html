How to read “Position”

Position is not a page number. It is the site's rank in Google's results, counting from #1 at the very top of the page down. Position 1 = the first result a patient sees. Positions 1–10 = Page 1; 11–20 = Page 2. Search Console reports an average, so #8.2 means the site typically shows up as about the 8th result on Page 1.
